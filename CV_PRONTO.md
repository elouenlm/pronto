# Texte CV - Projet PRONTO

## Version francaise

**PRONTO - Audit et visualisation de la qualite des donnees educatives**  
Projet academique, IMT Atlantique | Python, Pandas, NumPy, Streamlit, Plotly, scikit-learn

- Developpe un pipeline d'audit base sur le framework LADIQ : completude, coherence, exactitude, actualite et intelligibilite.
- Nettoye et controle des donnees educatives publiques relatives a l'IPS et aux resultats du DNB.
- Analyse la relation IPS-DNB avec correlation, Random Forest et courbes ALE (Accumulated Local Effects).
- Concu un dashboard Streamlit interactif avec filtres, KPI, visualisations statistiques et analyses regionales.
- Documente les choix methodologiques, les limites des indicateurs et les resultats dans une interface exploitable.

**Mots-cles ATS :** Python, Pandas, NumPy, scikit-learn, Streamlit, Plotly, data quality, data cleaning, data validation, exploratory data analysis, statistical analysis, Random Forest, ALE plots, data visualization, dashboard, open data, Git.

**Liens a ajouter dans le CV :** Demo interactive | Code source GitHub

## Version anglaise

**PRONTO - Educational data quality audit and interactive dashboard**  
Academic project, IMT Atlantique | Python, Pandas, NumPy, Streamlit, Plotly, scikit-learn

- Built a data quality audit pipeline based on the LADIQ framework.
- Cleaned and validated public education datasets covering social position indicators and national exam results.
- Studied the IPS-DNB relationship using correlation analysis, Random Forest and Accumulated Local Effects.
- Developed an interactive Streamlit dashboard with filters, KPIs, statistical charts and regional analysis.
